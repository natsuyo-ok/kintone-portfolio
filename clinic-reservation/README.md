# 医療機関向け予約管理システム

## 1. システム概要

kintoneと外部Webサイトを連携させた、医療機関向け予約管理システムです。

予約枠の生成・管理、Webからの予約受付、キャンセル処理、来院受付および診察案内までを一元的に管理することを目的として開発しています。

フロントエンドにHTML・CSS・JavaScript、サーバーサイドにPHP、データ管理基盤にkintoneを使用しています。

※本システムはポートフォリオ用のデモシステムです。一部機能は開発・検証中です。

## 2. システム構成

### kintoneアプリ

| アプリ | 主な役割 |
|---|---|
| 予約枠生成 | 対象年月に応じた予約枠の生成 |
| 予約枠管理 | 予約日・時間帯・残数・キャンセル数の管理 |
| 予約受付 | 予約者情報・予約番号・受付状況の管理 |
| 通知・呼出 | 来院受付および診察案内の管理 |

### 外部Webサイト

- 予約枠一覧画面
- 予約申込画面
- キャンセル画面（開発・検証中）

## 3. システム連携

### 予約受付の処理フロー

1. 利用者がWebサイトにアクセスする
2. JavaScriptからPHPのAPIエンドポイントを呼び出す
3. PHPがkintone REST APIを利用して予約枠情報を取得する
4. 予約可能な枠をWebサイトに表示する
5. 利用者が予約情報を入力する
6. PHPを経由してkintoneに予約データを登録する

### システム構成図

```text
[利用者]
   |
   v
[予約Webサイト]
 HTML / CSS / JavaScript
   |
   | HTTPリクエスト
   v
[PHP API]
   |
   | kintone REST API
   v
[kintone]
   |-- 予約枠生成
   |-- 予約枠管理
   |-- 予約受付
   |-- 通知・呼出
```

## 4. 主な機能

### 4.1 予約枠生成・管理

- 対象年月に応じた営業日の予約枠生成
- 休診日を考慮した予約枠管理
- 午前・午後の時間帯別管理
- 予約可能数およびキャンセル数の管理

#### デモ用の診療条件

| 項目 | 設定 |
|---|---|
| 月・火・水・金 | 午前・午後 |
| 木・日 | 休診 |
| 土 | 午前のみ |
| 午前予約枠 | 70名 |
| 午後予約枠 | 70名 |

### 4.2 Web予約受付

- 外部Webサイトから予約枠情報を取得
- 予約申込情報をkintoneに登録
- 予約日・時間帯と予約情報の関連付け

### 4.3 キャンセル管理（開発・検証中）

キャンセル発生時の予約枠補充を考慮した設計です。

- キャンセル件数の管理
- キャンセルによる補充可能枠の管理
- 満枠後のキャンセル枠再利用を想定

### 4.4 来院受付・診察案内

kintone上で患者の受付状況を管理する機能です。

- ボタン操作による来院受付
- ステータスに応じたボタン表示制御
- 中待合への案内状況の管理
- レコード更新時のrevisionを考慮した処理

※外部システムとの連携を含む一連の運用については、引き続き検証を行っています。

## 6. 設計上のポイント

### 外部Webサイトとkintoneの役割分離

利用者向けの予約画面と、医療機関側の管理画面を分離しています。

### APIを利用したデータ連携

PHPを経由してkintone REST APIを呼び出し、外部Webサイトから予約情報を扱う構成としています。

### 予約枠とキャンセル枠の管理

予約枠の残数だけでなく、キャンセル発生時の再受付も考慮しています。

### ステータス管理

来院受付から診察案内までの業務フローを整理し、画面上の操作とステータスを連動させています。

### データ更新時の整合性

kintoneのrevisionを利用した更新競合の検知を考慮しています。
