# 医療機器管理システム

## 1. システム概要

医療機器の点検記録・点検履歴を一元管理することを目的とした、kintoneベースの業務管理システムです。

点検種別に応じた点検項目の自動生成や、点検番号の自動採番、PDF出力などをJavaScriptで実装しています。

※本システムはポートフォリオ用のデモシステムです。

## 2. システム構成

### 主な管理対象

- 医療機器マスタ
- 点検項目等の各種マスタ
- 点検記録
- 点検履歴

### データ構造

点検記録アプリでは、点検項目をサブテーブルで管理します。

点検種別に応じて必要な点検項目を生成し、記録する構成です。

## 3. 主な機能

### 点検項目の自動生成

- 点検種別に応じた点検項目の取得
- サブテーブルへの点検項目の自動設定
- 手入力作業の削減

### 点検番号の自動採番

- 点検記録を識別する管理番号の生成
- 記録管理の効率化

### PDF出力

- 点検記録をPDF形式で出力
- JavaScriptおよびjsPDFを利用

### マスタ管理

- 医療機器情報の管理
- 点検項目等のマスタ管理

## 4. 使用技術

| 技術 | 用途 |
|---|---|
| kintone | 業務アプリ・データ管理 |
| JavaScript | 入力支援・採番・PDF生成 |
| kintone JavaScript API | 画面イベント・レコード操作 |
| kintone REST API | レコードデータの取得・操作 |
| jsPDF | PDFファイル生成 |

## 5. 想定業務フロー

1. 医療機器および点検項目のマスタ情報を登録する
2. 点検記録を新規作成する
3. 点検種別を選択する
4. 点検項目を自動生成する
5. 点検結果を入力・保存する
6. 必要に応じてPDFを出力する

## 6. 設計上のポイント

- マスタと点検記録を分離して管理する
- 点検種別に応じて入力項目を動的に生成する
- サブテーブルを利用して複数の点検項目を管理する
- JavaScriptで入力作業を効率化する
- PDF出力により記録の共有・保管を支援する
