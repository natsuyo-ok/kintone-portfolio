# kintone 業務システム開発ポートフォリオ

kintoneを中心に、JavaScript・REST API・PHPなどを活用して開発した業務システムのポートフォリオです。

業務フローの整理からアプリ設計、カスタマイズ、外部システム連携までを想定し、実務での運用を意識して制作しています。

## 制作システム

### 1. [設備点検管理システム](equipment-inspection/README.md)

設備の点検記録および是正対応を管理するシステムです。

* 点検記録・是正対応管理
* 各種マスタ管理
* JavaScriptによる入力支援・採番処理

### 2. [医療機器管理システム](medical-device-management　/README.md)

医療機器の点検履歴を管理するシステムです。

* 医療機器・点検項目のマスタ管理
* 点検種別に応じた点検項目の自動生成
* 点検番号の自動採番
* PDF出力

### 3. [医療機関向け予約管理システム（開発中）](clinic-reservation/README.md)

kintoneと外部Webサイトを連携させた予約管理システムです。

* 予約枠の生成・管理
* Webサイトからの予約受付
* PHPによるkintone REST API連携
* キャンセル管理機能
* 来院受付・診察案内のステータス管理

## 使用技術

* kintone
* JavaScript
* HTML / CSS
* PHP
* REST API
* GitHub

## 開発方針

業務上の課題を整理し、利用者にとって分かりやすく、保守・運用しやすいシステムの構築を目指しています。

※掲載するシステムは学習・技術検証を目的としたデモ作品です。実在する患者情報や業務上の機密情報は使用していません。

※ソースコード・操作マニュアル等は順次公開予定です。
